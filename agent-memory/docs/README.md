# Agent Memory

This directory is persistent project memory for coding agents.

## Files

- `architecture.md` — how the project is structured
- `current-state.md` — what is working and what remains
- `decisions.md` — important architectural decisions
- `debugging.md` — non-obvious bugs and fixes

## Rule

Keep these files short and useful.

Do not dump entire conversations into them.

Store durable knowledge, not chat history.
